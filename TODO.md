# Delivery outcomes

- [ ] Website menampilkan section Sertifikat yang membaca data dari source yang sama dengan admin panel, dengan metadata judul, penerbit, tahun, deskripsi, dan tautan verifikasi bila tersedia.
- [ ] Admin panel menyediakan upload sertifikat PDF/gambar, editor metadata, hapus file, dan penyimpanan metadata ke GitHub storage.
- [ ] Admin panel menampilkan jumlah sertifikat pada ringkasan dan memberi feedback loading, sukses, serta error yang jelas.
- [ ] Layout sertifikat dan dashboard tetap responsif, memiliki label form, focus state keyboard, dan touch target yang layak.
- [ ] Lint dan build production berhasil, lalu perubahan di-commit dan di-push ke branch `main` untuk memicu redeploy.
